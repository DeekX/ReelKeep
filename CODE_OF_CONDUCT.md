# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1.

In short: be respectful, assume good faith, welcome newcomers, and keep
discussion about the work. Harassment, insults and personal attacks are not
acceptable in issues, pull requests, reviews or any project space.

Reports go to the maintainer via GitHub (private vulnerability reporting for
security issues; a private issue or the contact in `SECURITY.md` otherwise).
Reports are reviewed promptly and kept confidential. Maintainers may remove
contributions or ban participants who violate this code.
