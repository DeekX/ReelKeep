## Name
ReelKeep — save to your private library

## Short description (132 chars max)
One-click save of pages, videos, images and notes to your own local-first library. No account, no cloud, no telemetry.

## Full description
ReelKeep is a private library for everything you want to keep — videos,
articles, images, audio, PDFs, notes and files — stored as plain files you own.
This extension adds one-click saving:

- Toolbar button opens a small form: type, folder, tags, notes, and optionally
  the current playback time of a video.
- Right-click any page, link, image or text selection to save it.
- Metadata (title, cover, description, site) is read from the page itself.
- Saves go to YOUR library: the companion server on your machine, a folder you
  picked, or browser storage. Nothing is sent to the author or any third party.
- If the library is unreachable, saves queue on your device and flush later.

Zero runtime dependencies in the library itself; the extension ships no remote
code and no analytics. See PRIVACY.md.
